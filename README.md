# PhysicalAI_AW2
Baseline (Payload Mass = 1): Actor hit the Payload and sent it sliding several units, easily covering the distance to the Goal Zone.

Test (Payload Mass = 10): Same Actor force and speed, but the collision transferred much less velocity to the heavier Payload (momentum is conserved in the collision, so a heavier object moves less for the same impact). The Payload barely shifted position, a few centimeters instead of several units. It never reached the Goal Zone in the same run duration.
